# World of Kashrut — עולם הכשרות
## מסמך אפיון מערכת מלא

> מערכת ניהול משרד לסוכנות כשרות — מהאקסל לפלטפורמה חכמה אחת.
> מסמך זה מתאר את **כל** מה שקיים במערכת כיום, את זרימת העבודה, ואת כיווני הפיתוח האפשריים עם יכולות 2026.

---

## 1. תקציר מנהלים

**הבעיה:** כיום המשרד מנהל את כל תיקי הכשרות בגיליון אקסל אחד גדול — עשרות תיקים, כל אחד עם יבואן, מפעל, משגיח, טיסות, מסמכים, דוחות, אבני-דרך (דו״ח → בדיקה → גוף כשרות → תעודה → רבנות → תשלום) ונתונים פיננסיים. האקסל פסיבי: לא מזכיר, לא מתריע, לא מתקשר, ולא יודע "מה דורש טיפול עכשיו".

**הפתרון:** פלטפורמה אחת שמחליפה את האקסל ומשדרגת אותו — מערכת **מונחית-תבניות מבוססת-כלים**:
- כל סוג עבודה מוגדר כ**תבנית** שבוחרת אילו **כלים** ו**דרישות** התיק צריך.
- כל **תיק** נוצר מתבנית ומקבל אוטומטית את כל הדרישות, עם **מעקב התקדמות באחוזים**.
- המערכת **אומרת לעובד מה לעשות** (מרכז משימות), **מתקשרת** (וואטסאפ/מייל בלחיצה), **מתעדת הכל** (יומן פעילות), ו**מתריעה** לפי כללים.

**הערך:** פחות טעויות, שקיפות מלאה, מעקב אחרי כל תיק, חיסכון בזמן, ותשתית לצמיחה.

## 2. משתמשים, תפקידים והרשאות

| תפקיד | מה רואה ועושה |
|-------|----------------|
| **מנהל (Admin)** | גישה מלאה: כל התיקים, ניהול תבניות, ניהול כלים, ניהול משתמשים, הגדרות התראות, אנליטיקות. |
| **מזכירה (Secretary)** | התיקים שבאחריותה, יצירה וניהול תיקים, תקשורת, מסמכים, דרישות. |

- **התחברות מאובטחת**: שם משתמש + סיסמה, סיסמאות מוצפנות (scrypt), עוגיית הפעלה חתומה (session). הרשאות נאכפות בשרת (לא רק בצד-לקוח).
- כל משתמש יכול לשנות את הסיסמה שלו; המנהל יכול להוסיף משתמשים, לאפס סיסמאות ולשנות הרשאות.

---

## 3. ארכיטקטורה טכנית (תמצית)

- **צד-לקוח:** Next.js 16 + React 19, עיצוב Tailwind, רכיבי Radix UI, גופן עברי Heebo, ערכת נושא לבן + זהב (מיתוג WK), תמיכה מלאה ב-RTL ובמצב כהה.
- **צד-שרת:** Next.js API Routes + Prisma ORM מול בסיס נתונים SQLite (ניתן להחלפה ל-PostgreSQL בענן).
- **אבטחה:** scrypt לסיסמאות, session חתום ב-HMAC, middleware שמגן על כל ה-API.
- **AI:** עוזר שיחה מבוסס מודל שפה עם גישה לנתוני התיקים.
- **אינטגרציה:** Google Drive (חשבון שירות).

## 4. הרעיון המרכזי — כלים, תבניות, תיקים, דרישות

```
ניהול כלים  ─┐
             ├──►  תבנית  ──►  יצירת תיק  ──►  תיק עם כלים ודרישות  ──►  מעקב % + תקשורת + יומן
ספריית כלים ─┘
```

- **כלי (Tool):** יחידת עבודה במסך התיק. יש **כלי ליבה** (תמיד פעילים) ו**כלים אופציונליים** (לפי בחירת התבנית).
- **דרישה (Requirement):** דבר אחד שצריך לבצע — מאחד מ-5 סוגים: **מסמך**, **שאלה**, **שדה למילוי**, **משימה**, **אישור**. לכל דרישה אפשר להגדיר **"מאת מי"** (המשרד / המשגיח / היבואן / המפעל) ואם היא **חובה**.
- **תבנית (Template):** מגדירה אילו כלים פעילים + אילו קבוצות דרישות. דינמית — ניתן ליצור תבניות חדשות לכל סוג ייצור.
- **תיק (Case/Project):** נוצר מתבנית, מקבל "צילום" של כל הדרישות, ומנהל את העבודה היומיומית.

**התקדמות התיק = אחוז הדרישות (חובה) שהושלמו** — לא "שלבים". פשוט וברור.

## 5. פירוט המסכים והמודולים

### 5.1 התחברות
מסך כניסה ממותג, בחירת משתמש + סיסמה, הודעות שגיאה ברורות.

### 5.2 דשבורד (מסך הבית) ✅
- **מרכז משימות (Action Center):** הלב של המערכת — רשימה חיה של **מה דורש טיפול עכשיו** מכל התיקים: עיכובים/חריגה מיעד, מסמכים לאישור, יבואנים שממתינים, טיסות להזמנה, והדרישה הפתוחה הבאה בכל תיק. לחיצה → קפיצה לתיק.
- **כרטיסי KPI:** משימות דחופות, דוחות לבדיקה, ממתינים למענה, רווח חודשי.
- **טבלת תיקים בסגנון גיליון:**
  - **עריכה ישירה בשורה** — סטטוס, אחראי/ת, "שולם", "דוח התקבל" (נשמר מיד).
  - **עמודת "מסלול כשרות"** — רצף נקודות שמראה במבט אחד באיזו אבן-דרך כל תיק (דו״ח → חיים → גוף כשרות → תעודה → רבנות → תשלום).
  - עמודות: פרויקט, יבואן, משגיח · גוף כשרות, התקדמות %, סטטוס, אחראי, תשלום · דוח.
  - **סינון** (לפי סטטוס), **מיון** (לחיצה על כותרת), **חיפוש**, ו**קיבוץ** (לפי אחראי / סטטוס / חודש) — בדיוק כמו עבודה בגיליון.

### 5.3 מסך התיק 📋
תפריט צד מאורגן לפי **כלים**, עם אחוז השלמה ו"מה חסר":

| כלי | תוכן |
|------|------|
| **סקירה כללית** | מסמך התיק המלא: פרטים כלליים, פיננסי, לוגיסטיקה, משגיח, כל הדרישות עם הערכים שמולאו. כפתורי **ייצוא לאקסל** ו**הדפסה/PDF**. |
| **פתיחה ופרטי יבואן** | יבואן, איש קשר, מדינה, גוף כשרות, מפעל — עריכה ושמירה אוטומטית. |
| **השגחה וטיסות** | פרטי משגיח, טיסה (הלוך/חזור/מספר), מלון — וסטטוסים. |
| **פרטי ייצור** | תאריכים, כמות, מרכיבים, איש קשר מקומי. |
| **מסמכים ודרישות** | כל המסמכים/השדות/המשימות מקובצים — העלאה, אישור/דחייה, מילוי, סימון, ולכל דרישה חיצונית כפתור **"בקש מ-X"**. |
| **אישורים** | גורמים מאשרים. |
| **תקשורת** | אנשי קשר מהירים (יבואן/משגיח — וואטסאפ/טלפון/מייל), **תבניות הודעה מוכנות**, וצ'אט פנימי + חיצוני. |
| **יומן פעילות** | פיד כרונולוגי אחד: כל השינויים (סטטוס/שדות) + כל התקשורת — "כל הסיפור של התיק". ניתן לייצוא. |

- **כפתורים גלובליים בתיק:** ייצוא לאקסל, פתיחת/קישור תיקיית Drive, וואטסאפ/טלפון/מייל ליבואן.
- **תווית דדליין חכמה** בכותרת (מחושבת מתאריך היעד מול היום — לא נתון סטטי).

### 5.4 תבניות 🧩
- גלריית תבניות (כולל "תהליך כשרות מלא — WK" שמשקף את האקסל, ותבניות לפי סוג: חלבי/בשרי/פרווה/יין/דגים/ירקות).
- **עורך תבנית** ברור:
  - **כלי ליבה** (מוצגים, תמיד פעילים) + **כלים אופציונליים** (toggles).
  - **קבוצות דרישות** — ארגון המסמכים/השדות/המשימות לקבוצות (למשל "פתיחה", "ייצור"), כל דרישה עם סוג, חובה, ו"מאת מי".
  - **הוספת כלי מהספרייה** — שליפת כלי מותאם מוכן.
  - שכפול, עריכה, ארכוב.

### 5.5 ניהול כלים 🛠️ (מנהל)
- **קטלוג כלי המערכת** — מה כל כלי עושה, מה תמיד-פעיל ומה אופציונלי.
- **ספריית כלים מותאמים** — יצירת כלים לשימוש חוזר (שם, אייקון, ודרישות עם "מאת"), שתבניות יכולות לשלוף. כך מרחיבים את המערכת בלי קוד.

### 5.6 יבואנים (CRM) 👥
כרטיס לכל יבואן: איש קשר, טלפון, מייל, מדינה, **כל התיקים שלו**, וכפתורי וואטסאפ/טלפון/מייל. הוספה ועריכה.

### 5.7 משגיחים
רישום משגיחים (שם, טלפון, מייל, גופי כשרות) — נמשך באשף יצירת התיק ובבקשות.

### 5.8 נסיעות ✈️
לוח חוצה-תיקים: מי טס, לאן, מתי, סטטוס טיסה+מלון, ו**"דורש הזמנה"** בראש — כל הלוגיסטיקה במבט אחד.

### 5.9 דוחות וייצוא 📊
- KPIs פיננסיים (הכנסות, הוצאות, רווח, חוב פתוח), תיקים לפי סטטוס, עומס לפי אחראי, וריכוז כל המסמכים.
- **ייצוא ל-Excel/CSV** (תיקים, מסמכים, יומן תיק) — גשר ההגירה מהאקסל.

### 5.10 התראות ⏰
- מנוע **מבוסס-כללים**: אירועים (איחור, חוסר דו״ח, מסמך נדחה, יעד מתקרב, ממתין לתשלום, יבואן ממתין), **נמענים** (אחראי/משגיח/יבואן/מנהל), וסף ימים.
- **מסך הגדרות** להפעלה/כיבוי לכל אירוע ובחירת נמענים. כיום ההתראות מוצגות **בתוך המערכת** (מרכז התראות); מייל/וואטסאפ — מוכן לחיבור.

### 5.11 כלים רוחביים
- **חיפוש מהיר Ctrl-K** — קפיצה לכל תיק/יבואן/פעולה מכל מסך.
- **עוזר AI** — צ'אט ששואלים אותו על התיקים ("אילו תיקים ממתינים לדוח?", "מה הרווח החודש?").
- **Google Drive** — יצירת תיקיית-תיק אוטומטית וקישור ממסך התיק.

## 6. אבני-הדרך של תהליך הכשרות (מיפוי מלא לאקסל)

המערכת עוקבת אחר כל אבני-הדרך מהגיליון, **מסונכרנות דו-כיווני** בין הצעד בתיק לדגל בדשבורד:

| # | אבן דרך | מקור |
|---|---------|------|
| 1 | התקבל דו״ח ייצור מהמשגיח | משגיח |
| 2 | נשלח לחיים לבדיקה | משרד |
| 3 | הועבר דו״ח + תווית לגוף הכשרות | משרד |
| 4 | התקבלה תעודת כשרות | גוף הכשרות |
| 5 | הוגש לרבנות (+ מספר אסמכתא) | משרד |
| 6 | הוגש לתשלום | משרד |
| 7 | שולם | משרד |

סימון בתיק ↔ דגל בטבלה תמיד מסונכרנים (מקור-אמת אחד). הרווחים: עמלת יום, אגרת כשרות, הגשה לרבנות — נשמרים בתיק.

## 7. זרימת העבודה מקצה לקצה

1. **הגדרה (חד-פעמית):** המנהל מגדיר כלים ותבניות לסוגי הייצור.
2. **פתיחת תיק:** בחירת תבנית + פרטים ראשוניים בלבד → המערכת בונה את כל הדרישות והכלים אוטומטית, ויוצרת תיקיית Drive.
3. **עבודה יומיומית:** העובד נכנס לתיק, רואה מה חסר, ממלא שדות/מעלה מסמכים/מסמן משימות, ו**מבקש בלחיצה** מהמשגיח/יבואן מה שצריך (וואטסאפ ממולא מראש).
4. **מעקב:** הדשבורד ומרכז המשימות מציגים מה דורש טיפול, באיזו אבן-דרך כל תיק, ומה באיחור.
5. **סגירה:** אבני-הדרך מסומנות עד התשלום; הכל מתועד ביומן וניתן לייצוא.

## 9. כיווני קידום ושיפור עם יכולות 2026

**אוטומציה ו-AI (הזדמנות הגדולה):**
- **קריאת מסמכים אוטומטית (OCR + AI):** העלאת דו״ח/תעודה → המערכת מחלצת תאריכים, מספרי אסמכתא ופרטים וממלאת את השדות לבד.
- **עוזר AI פרואקטיבי:** "מה דחוף השבוע?", ניסוח טיוטות הודעות למשגיח/יבואן, סיכום תיק, וזיהוי חריגות ("תיק תקוע 10 ימים בשלב התעודה").
- **חיזוי דדליינים** והמלצות תיעדוף חכמות.

**תקשורת ואינטגרציות:**
- **WhatsApp Business API** + **מייל אוטומטי** — שליחת בקשות ותזכורות אוטומטית לפי כללי ההתראות (לא רק בלחיצה).
- **חתימה דיגיטלית** על מסמכים/אישורים.
- **סנכרון דו-כיווני ל-Google Sheets** (למי שרוצה גם גיליון), וייצוא PDF ממותג.
- **חיבור להנהלת חשבונות/חשבוניות** (חיוב אוטומטי בסיום תיק).

**חוויית משתמש ותשתית:**
- **אפליקציית מובייל / PWA** למשגיחים בשטח (העלאת תמונות ודוח מהשטח).
- **לוח שנה** של ייצורים ונסיעות, ו**דשבורד אנליטיקות** (רווחיות לפי גוף כשרות/משגיח/מדינה, זמני מחזור).
- **פורטל יבואן/משגיח** — גישה מוגבלת להעלאת מסמכים ומעקב סטטוס.
- מעבר לבסיס נתונים בענן (PostgreSQL) ואחסון קבצים בענן לפריסה יציבה.
